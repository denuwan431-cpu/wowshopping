# Storefront update

- Light professional storefront styling for header/footer and secure private admin area.
- Public UI no longer exposes Register, Account, or Admin Panel links.
- Header menu supports Home, Shop, Kids, Adults, Special Offers and Contact Us.
- Kids/Adults nested menu configuration is editable from `/admin/settings`.
- Customer Care footer links, social links and payment methods are editable/hideable.
- Payment methods support optional logo URLs.
- Hero supports an MP4/WebM video URL plus poster/fallback image.
- Product API already supports product create/update/delete; the admin product catalog can manage product names and visibility.
- New Store Control Center at `/admin/settings` is protected by admin session checks.
